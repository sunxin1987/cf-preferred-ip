优选完怎么用

拿到优选 IP 后，按你用的工具填进去就行，常见有三种场景：

01

代理 / 加速工具

把优选 IP 填到节点的「自定义 IP / 优选地址」一栏，端口保持原节点的端口不变，只换地址。

02

域名解析（自建服务）

把域名的 A 记录（IPv4）或 AAAA 记录（IPv6）改成优选 IP，源站和回源设置不用动。

03

本机 hosts

一行一条：优选IP 域名。只对这台设备生效，测新 IP 前记得先删旧行再测，避免测到缓存。

  • 浏览器测不了 ICMP ping 和 TCP 握手，这里测的是向该 IP 发起 HTTPS 请求的往返耗时（含连接失败的返回时间），适合在同一网络下横向比较，别和 ping 的数字直接对比。
  • 状态显示「有响应」表示该 IP 在超时内返回了动静（证书不匹配等原因请求没成功，但机器是活的、速度可比）；「无响应」表示超时内毫无动静。
  • 优选结果只对测速这一刻、这条网络有效；晚高峰、换地点、换运营商都会变，觉得变慢了就重测。
